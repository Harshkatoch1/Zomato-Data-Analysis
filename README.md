# Zomato Data Analysis Project

## Project Overview
This project analyzes Zomato restaurant data using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Data Cleaning
2. Rating Analysis
3. Restaurant Type Analysis
4. Vote Analysis
5. Cost Analysis
6. Online vs Offline Orders
7. Heatmap Visualization

## Key Findings

- Dining restaurants receive the highest number of votes.
- Most restaurants have ratings between 3.5 and 4.
- Couples prefer restaurants costing around ₹300 for two people.
- Dining restaurants mostly receive offline orders.
- Cafes receive more online orders.
